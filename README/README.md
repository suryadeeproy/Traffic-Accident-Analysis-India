# 🚦 Traffic Accident Analysis in India

## 📌 Project Overview

Traffic Accident Analysis in India is a complete data analysis and visualization project developed using Python and Power BI.  
The objective of this project is to analyze Indian traffic accident data and identify important accident patterns based on:

- States
- Cities
- Weather conditions
- Road types
- Peak accident hours
- Weekday vs weekend accidents
- Risk score analysis

This project combines:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Interactive Dashboard Design

The project helps in understanding accident-prone conditions and provides meaningful insights for road safety analysis.

---

# 🎯 Project Objectives

The main objectives of this project are:

✅ Analyze traffic accident trends in India  
✅ Identify states with the highest accidents  
✅ Identify cities with frequent accidents  
✅ Analyze weather impact on accidents  
✅ Study accident frequency during peak hours  
✅ Compare weekday and weekend accidents  
✅ Build an interactive Power BI dashboard  
✅ Practice real-world data analyst workflow
